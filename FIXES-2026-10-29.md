# Erangel Strike — targeted fixes

This patch preserves the React/Three.js enhanced project and makes three targeted changes:

1. **Stair safety:** both sides of each interior stair ramp now have visible railings and continuous collision barriers. The barriers are collision-only and follow the full ramp height, so the player is pushed back instead of slipping off the edge.
2. **Bot line of sight:** visibility is invalidated whenever a bot changes targets, the ray uses the full 3D distance to the target, and bots re-check the shot before firing. This prevents stale visibility from a previous target or a target moving behind a wall from allowing shots through cover.
3. **Reliable rebuilds:** `npm run dev` and `npm run build` now run `scripts/build-game.mjs` first, so the standalone game bundle is regenerated from `src/game/engine.js` rather than silently serving an older copy.

## Verify

```sh
npm install
npm run build
npm run dev
```

Then test stair edges in a two- or three-story building and test whether bots stop firing when a wall is between them and the player. The changes were syntax-checked, but a full browser smoke test was not completed in the patching environment.
